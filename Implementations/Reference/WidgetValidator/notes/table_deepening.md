<h1 align="center">Table Widget Deepening Notes</h1>

<p align="center">
  <strong>Current qualitative deepening pass for the FROG Table widget family</strong><br/>
  <em>FROG — Free Open Graphical Language</em>
</p>

<hr/>

<h2>What Changed</h2>

<p>
The Table family now has a fuller public surface for structured tabular data:
</p>

<ul>
  <li>structured <code>frog.table</code> value model,</li>
  <li>column schema and row identity posture,</li>
  <li>cell-level public access,</li>
  <li>selection, active cell, and range posture,</li>
  <li>editing posture,</li>
  <li>viewport and scrolling posture,</li>
  <li>sort and filter posture,</li>
  <li>header, grid, body, row, cell, selection, edit, resize, and scrollbar parts.</li>
</ul>

<hr/>

<h2>Boundary</h2>

<p>
Table remains a flat tabular widget family.
Tree tables, spreadsheet formula languages, database views, pivot tables, and host-native virtual grid engines remain downstream from this intrinsic class law unless explicitly standardized elsewhere.
</p>
