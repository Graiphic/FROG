# Studio authoring envelope example

`minimal.frog` is a hand-authored structural documentation example of readable
revision 2. It is not canonical `spec_version` source, is not a new public native
execution fixture and has not been executed in Studio by this reconciliation.
It demonstrates the existing writer-shaped envelope without user data or
private machine paths. Historical import, provider behavior and complete
read/write/read validation remain the product's own tests.
