# Studio implementation and public corpus — 26 October 2026

This dated update reconciles the public corpus with the earlier 14 October
authoring snapshot. It does not change the normative language specification,
publish proprietary Studio implementation or certify every target.

## Published material

The public SDK and native-example lot was published as
[`f24b69cf`](https://github.com/Graiphic/FROG/commit/f24b69cf14d64d5345d6f542ab342a10b6f7bde2).
The subsequent navigation refresh is
[`26e27b48`](https://github.com/Graiphic/FROG/commit/26e27b483d401ab3ac4c15bceb61f88859ca2206).
The reference checks and Pages deployment completed successfully for those
revisions. This is public-repository evidence, not a complete Studio test gate.

The existing [canonical example index](../Examples/index.v1.json) lists **625
documents**: 610 execution scenarios, eight expected diagnostics, three
expected stops and four persistence scenarios. Named backends and expected
outputs are declarations. A successful expected refusal is not a new admitted
calculation, and persistence is not execution support.

These files retain their actual **Studio Draft** envelopes. Publishing them
here does not convert them into public Source 0.1. Draft revision, Studio
version and public Source compatibility version remain separate identities.

## Product evidence and reference scope

The [Studio capability checkpoint](https://graiphic.github.io/Graiphic-Studio/#/docs/reference/development-checkpoint)
records the separate 25 October measurement: **1,219 successful checks** across
Native Fast, Native Debug, explicit private Simulation and persistence. Its
results are dated and scoped to the listed files and modes; they do not
establish every function, overload or operating-system provider.

The current product documentation projects **678 active function contracts in
18 families**. The original audit had 761 identities, of which 83 ActiveX,
Database, DataFinder and Web Services identities were withdrawn. They are future
extension areas, not active product palette entries.

The [14 October profile](../Profiles/StudioAuthoring.md) remains a historical
535-contract snapshot. Its copied manifests and hashes are preserved. They
must not be mistaken for the current product inventory or silently edited into
a new normative contract. The newer product reference preserves original
binding declarations while distinguishing measured native profiles.

The public README and Project Status now point here. Their older dated
implementation tables remain historical material. Language contracts,
authoring metadata, native admission, a successful example run and full product
qualification continue to describe different evidence.

## Documentation-only refresh

The 26 October documentation work updates guides for Run/Highlight, standalone
Build, standard Type Def, Tab Controls, String display and attached comments.
It also replaces old example artwork with the existing diagram SVGs. Comparing
the 625 old documentation downloads with the canonical corpus found differences
only in `icon`; graphs and values were identical. Historical runtime file hashes
remain historical and are not rewritten as a new run of the updated artwork.

The application-wide regression suite remains paused. This refresh neither
builds Studio nor changes the capabilities of a running program.
