## Remaining gaps are part of the specification record

1. Normal private Run can start without Highlight, but the code still uses its
   timed simulation owner. Masking Highlight does not prove removal of 150/500 ms
   node/wire pacing. Native compiled While/I64/Boolean operation is not declared
   delivered by the flat f64/Add qualification.
2. Sondes and complete before-node/conditional/hierarchical breakpoints require
   actual target admission, commands, safe suspension and same-instance resume.
   A declared API or user prompt is not a product proof.
3. Public Source editing and migration cover bounded profiles, not arbitrary
   conversion of every private catalogue item to portable canonical semantics.
4. New reference widgets/Cluster reference values in the active working tree
   require their own compilation and tests before delivery claims.
5. Full regression remains paused. Static documentation/schema checks from this
   pass do not replace native, migration or full-suite qualification.
