<h2>Label Realization Note</h2>

<p>
For <code>frog.widgets.label</code>, <code>label.text</code> remains the logical object name, while <code>text.value</code> is the visible support text. The Default SVG template provides a text surface and optional frame/background, but it does not own <code>text.value</code>.
</p>
