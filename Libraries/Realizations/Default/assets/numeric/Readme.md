<h2>Overview</h2>

<p>
This directory contains the SVG template assets used by the Default numeric realization family.
</p>

<ul>
  <li><code>templates/numeric_rectangular.svg</code> — semantic template for numeric controls and numeric indicators</li>
</ul>

<p>
The SVG is intended to be interpreted as a template with dynamic parts, not as a frozen artwork.
</p>
