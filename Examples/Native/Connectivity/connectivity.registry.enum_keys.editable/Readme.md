# Édition uniquement — Énumérer les sous-clés

Suivre la référence de clé depuis son obtention jusqu’à Close Key. Le chemin et les noms sont des valeurs pédagogiques. Ce montage est destiné à l’édition.

Déplacer un élément ou modifier une constante, puis sauvegarder et rouvrir le montage. La validation porte sur le document et ses connexions. Le fournisseur d’exécution de cette rubrique reste indisponible dans Studio.
