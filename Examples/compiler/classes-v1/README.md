# Capteur — fixture de définitions

Fixture redistribuable sous Apache-2.0. Ces quatre définitions vérifient l’identité nominale, l’héritage et la table des cibles du Frontend. Les références aux FROG membres décrivent le connecteur à réaliser ; les corps ne sont pas fournis. Ce répertoire n’est pas un exemple exécutable ni une entrée de Find Examples. Voir le [contrat local](../../../docs/proposals/classes-v1.md).
