<h1 align="center">Array Reference Snapshots</h1>

<p align="center">
  <strong>Accepted public visual dossiers for the current Array widget progression</strong><br/>
  <em>FROG - Free Open Graphical Language</em>
</p>

<hr/>

<h2>Scope</h2>

<p>
This page collects the public Array reference snapshots that were added after the
initial Example 05-30 reference batch. Each linked page embeds its accepted
snapshot directly and links the accepted state JSON, visual contract,
machine-readable contract, and artifact index.
</p>

<p>
These records are public evidence only. They do not publish Graiphic private
runtime source and they do not redefine the FROG language specification.
</p>
